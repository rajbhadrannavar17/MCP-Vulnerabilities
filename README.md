# PortSwigger MCP Vulnerabilities Labs

Six hands-on MCP security lab writeups, presented as a GitHub Pages site.

## Publish the site

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select
`main` and the `/(root)` folder, then save. The site will be available at:

[https://rajbhadrannavar17.github.io/MCP-Vulnerabilities/](https://rajbhadrannavar17.github.io/MCP-Vulnerabilities/)

## Solved-state screenshots

Place genuine screenshots in `screenshots/` using the filenames listed in
[`_data/labs.yml`](_data/labs.yml). The site displays each image on its lab card.
